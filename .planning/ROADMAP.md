## フェーズ詳細

### Phase 1: ソース別タブ UI
**Goal**: ユーザーが画面上部のタブでニュースソースを切り替えて、そのソースの記事だけを閲覧できる
**Mode:** mvp
**Depends on**: なし（既存コードベースが基盤）
**Requirements**: SRC-01, SRC-02, SRC-03, SRC-04, SRC-05
**Success Criteria** (what must be TRUE):
  1. ユーザーはページ上部に「すべて / Zenn / はてブ / Google ニュース / Togetter」のタブを見ることができる
  2. ユーザーはタブをクリックするとそのソースの記事だけに絞り込まれ、他のソースの記事は表示されない
  3. ユーザーがソースを絞り込んでも、直近3日以内の記事のみが表示される（表示期間は変わらない）
  4. ユーザーがページを最初に開いたとき、またはリロードしたとき、「すべて」タブが選択された状態で表示される
  5. ユーザーが選択したソースに直近3日の記事がない場合、「記事がありません」というメッセージが表示される
**Plans**: 1 plan
- [x] 01-01-PLAN.md — ソース切り替えタブ UI（SourceTabs Client Component + articles.ts ヘルパー + page.tsx 配線、E2E/ユニットテスト付き）
**UI hint**: yes
