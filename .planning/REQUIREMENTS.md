# Requirements: news.hako.tokyo

**Defined:** 2026-05-30
**Core Value:** 直近のニュース記事を、見たいソースごとにすばやく切り替えて閲覧できること

## v1 Requirements

初期リリースの要件。各要件はロードマップのフェーズにマッピングされる。

### ソース別タブ表示

- [ ] **SRC-01**: ユーザーは画面上部のタブ（すべて / Zenn / はてな / Google News / Togetter）を見ることができる
- [ ] **SRC-02**: ユーザーはタブをクリックして、そのソースの記事だけにクライアント内で絞り込める
- [ ] **SRC-03**: ユーザーがソースで絞り込んでも、直近3日の記事のみが表示される（既存の表示期間を維持）
- [ ] **SRC-04**: ユーザーが最初にページを開いたとき、およびリロード後は「すべて」タブが選択された状態で表示される
- [ ] **SRC-05**: ユーザーが選択したソースに直近3日の記事がない場合、「記事がありません」というメッセージが表示される

## v2 Requirements

将来リリースに延期。追跡はするが現在のロードマップには含めない。

### ソース別タブ表示（拡張）

- **SRC-06**: タブに件数バッジ（例: Zenn (12)）を表示する
- **SRC-07**: タブの選択状態を URL に反映し（例: `/?source=zenn`）、ブックマーク/共有可能にする

## Out of Scope

明示的に除外。スコープクリープを防ぐために記録する。

| Feature | Reason |
|---------|--------|
| 複数ソースの同時選択（マルチセレクト） | 1ソースずつの切り替えで要件を満たすため |
| ソースごとの独立ページ/ルーティング | クライアント切り替えで十分なため |
| 表示期間（直近3日）の変更・ソース別の期間調整 | 既存挙動を維持し、今回のスコープ外 |
| `Article` モデルへの新フィールド追加 | 既存の `SourceId` を利用するため不要 |
